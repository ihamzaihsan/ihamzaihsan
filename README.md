## About me

I build software across backend systems, web applications, algorithms, and interactive experiences. I work in Go, Rust, JavaScript, and TypeScript, and I enjoy understanding how applications behave beneath the interface: data, networking, state, and performance.

My work includes HTTP services, TCP chat, WebSocket communication, authentication, and SQLite backed features; React and Next.js interfaces, browser games, and SVG data visualization; and graph algorithms, simulations, and graphics. I value clear implementation, testing, and iteration.
