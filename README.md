# Hamza Cheema

Software developer working across backend systems, web applications, algorithms, and interactive software. I build in Go, Rust, JavaScript, and TypeScript, with a particular interest in how applications behave below the interface: data, networking, state, and performance.

## What I build

- **Backend and networking:** HTTP services, TCP chat, WebSocket communication, SQLite backed features, authentication, sessions, and file uploads.
- **Web and interactive interfaces:** React and Next.js applications, browser games, custom DOM rendering, and SVG data visualization.
- **Algorithms and graphics:** graph traversal and path finding, constrained sorting, collision avoidance, simulation, and a software ray tracer.
- **Practical engineering:** SQL migrations and transactions, input validation, Dockerfiles, and focused automated tests.
